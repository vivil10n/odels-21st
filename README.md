# Odel’s 21st 🌏

A digital birthday letter I made for my friend Odel’s 21st.

We met while studying abroad in Tokyo and became close during the brief time we lived in the same city. When exchange ended, he returned to San Francisco and I came home to Sydney. A friendship that had once been part of everyday life was suddenly separated by an ocean.

I made this site to send him the words I could not give him in person 💌

### [View the birthday letter →](https://vivil10n.github.io/odels-21st/)

## Built with

* HTML
* CSS
* JavaScript
* GitHub Pages

## About the design

I wanted the site to feel like a quiet digital keepsake—warm, wistful and made to be held onto.

It celebrates Odel’s 21st, but it is also about missing someone far away. It holds a small part of our time in Tokyo and lets that care travel from Sydney to San Francisco.

Designed and built by [Vivian Truong](https://www.vivitruon.com/) for Odel.
